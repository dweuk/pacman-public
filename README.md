# 42 Pacman

Play and watch the game here: **[dweuk.itch.io/42-pacman](https://dweuk.itch.io/42-pacman)**

## Duo mode

Two players, one keyboard: Player 1 is Pac-Man (arrow keys), Player 2 is a ghost (W A S D).
Pac-Man wins by clearing all the levels; the ghost wins by catching Pac-Man first.
A super-pacgum turns the hunter into the prey for a short time.

## Hand-drawn art

Pac-Man, the ghosts and the fruits were all drawn by hand, which gives the arcade classic a wobbly, marker-like look.

## What makes it good

- **Two kinds of mazes:** procedurally generated 42-style mazes, or classic Pac-Man layouts.
- **Real ghost AI:** Blinky, Pinky, Inky and Clyde each have their own personality, with scatter, chase and frightened phases.
- **Ready to play:** builds for Linux and Mac on itch.io, no Python needed.
- **Hard to crash:** an invalid config falls back to safe defaults, so the game always starts.
